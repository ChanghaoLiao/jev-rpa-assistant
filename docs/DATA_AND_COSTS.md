# 数据与可追溯性

## 存储位置

默认根目录为 `%LOCALAPPDATA%\JevReplyTool`；设置 `JEVTOOL_DATA_DIR` 可改用独立根目录。
源码资源与用户可写数据分开，复制示例时不覆盖已有用户文件。

| 位置／表 | 内容 |
|---|---|
| `config.local.json` | 服务、账号和验收配置，可能含明文密钥，不提交 |
| `.locator/` | 商家的 Clicknium 录制文件与备份，不提交 |
| `audit.sqlite3` 的 `trace`／`attachments` | 全局操作链、异常、阶段与附件证据 |
| `profiles/<账号>/events.sqlite3` 的 `events` | 消息指纹、候选、发送与处理状态 |
| `blocked`／`frames`／`preview_whitelist` | 客户暂停、画面去重与预览测试状态 |
| `vision_audit` | 实际 PNG 字节、模型返回、转录、决策与错误 |
| `operation_log`／`run_logs` | 业务操作与显示日志 |
| `api_calls`／`api_rates` | API 尝试、用量、调用时单价与费用估算 |
| `acceptance_flows` | 图片、识字、话术核对、用户确认和测试发送衔接 |
| 话术版本库的 `versions` | 导入原件、预览、启用和恢复所需索引 |

候选和观察基线有内存状态，重启后不从历史直接恢复可发送候选。
发送记录、暂停客户、审计与话术版本持久保存。

## 一次操作如何追踪

启动会话 → 操作编号 → 子步骤／API 尝试 → 识字与决策记录 → 发送阶段 → 结果。
记录包含时间、平台、客户、阶段、结果、耗时和脱敏异常。
点击意图先同步持久化，点击调用返回不等于发送已确认。
重启发现未完成发送时保留未知状态，不自动补发。

## 费用含义

- 记录每次 API 尝试，重试也单独留存。
- 根据模型返回用量、缓存用量、计价方式和调用时单价估算。
- 供应商未返回用量或无法定价时显示未知，不当作零成本。
- 不同币种及计费口径分开汇总；不会自动读取供应商余额。
- 估算不能替代真实账单；密钥、模型、套餐和价格变化后应重新核对计价。

## 隐私边界

日志会对注册密钥、认证字段和部分 token 格式脱敏，但不意味着客户聊天或截图已经匿名。
诊断包可能仍含商业和个人信息，分享前必须再次检查。
删除程序并不等于删除用户数据；备份恢复需同时考虑数据库与配置。
仓库不提供真实运行数据库、客户截图、密钥、聊天原文或商家录制库。
