# 话术库格式与审核

## 七列格式

Excel 第一张工作表或 UTF-8 CSV 使用以下列名，保持拼写一致。

| 字段 | 含义 |
|---|---|
| `category_path` | 用 `/` 分隔的分类路径，例如 `物流/配送查询` |
| `reply_id` | 唯一话术编号，不能重复 |
| `when_to_use` | 客户什么问题、哪些已知条件下适用 |
| `when_not_to_use` | 哪些情况排除，哪些信息应先核实 |
| `reply_text` | 可以直接发送的完整固定正文 |
| `approved_for_auto` | 商家是否批准自动使用，使用 true／false |
| `requires_human` | 是否必须人工处理，使用 true／false |

仓库 `knowledge/replies.csv` 是填写与流程示例，不代表任何商家的价格、日期或承诺；默认未批准自动发送。
一条回复只有已批准、无需强制人工且通过运行时检查，才可能被自动使用。
改动审批不等于开启自动发送。

## 分类说明

`categories.json` 用分类路径映射到说明文字，帮助 Jev 区分相近类别。
程序依据 CSV 构建树，每次只向模型提供当前目录选项。
添加同类问题通常只需加话术；新增类别还应补充清晰的类别说明并测试边界。
不能把每个新问法都当作新类别，也不要写无法验证的承诺。

## 导入与版本

1. 选择文件后校验表头、重复编号、布尔标记及内容格式。
2. 先预览；错误给出对应行，失败不会替换当前库。
3. 用户审核后启用，当前生效路径以配置为准。
4. 版本文件不可覆盖，恢复先预览确认，不删除历史版本。
5. 修改话术后重新测试代表性问题；重启后的可发送候选仍须重新读取真实会话。

填写模板不使用 Excel 公式、宏或真实订单数据。长回复及多种问法可在单元格内换行。
