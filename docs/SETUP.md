# 配置与使用

## 前置条件

- Windows 桌面环境；发布测试使用 Python 3.13。源码安装需自行安装 Python。
- 图形界面安装 `requirements-windows.txt`；完整离线测试也需要这组依赖。
- 自己的 Jev 与视觉服务账号；不提供密钥，也不包含调用额度。
- 操作聊天页需 Clicknium SDK、对应浏览器扩展；录制需 VS Code 与 Clicknium 录制器。
- 使用本人可控制的测试会话完成真实发送验收。

模型、依赖安装与授权可能变化。示例配置不是服务有效性的证明，具体可用性需分别测试。
本源码包未附带商业 SDK 二进制、字体文件或安装器。

## 隔离演练

运行前在 PowerShell 指定独立目录：

```powershell
$env:JEVTOOL_DATA_DIR = Join-Path $PWD '.local-data'
```

这样不会默认读取你已经在 `%LOCALAPPDATA%\JevReplyTool` 中保存的配置。
不要为跳过验收而手动把配置中的布尔标记改为 true。

## 六步向导

1. **连接服务：**填写地址、模型和密钥。保存不等于测试成功，Jev 与视觉测试分别记录。
2. **平台与录制：**录制下表五个目标。闲鱼＋Edge 可自动接入、整理未读规则并核对页面，其他平台需要独立适配。
3. **验证窗口：**四个固定目标须唯一匹配；未读会话可以有零个或多个，零个表示等待测试消息。
4. **导入与审核：**第一张 Excel 工作表或 UTF-8 CSV 使用七列格式；预览通过后明确审核并启用。
5. **验收接待：**先上传 PNG 识字并人工核对，再复用结果测试选话术；随后重新读取真实测试会话，确认收件人与正文后测试发送一次。
6. **准备完成：**依据实际验收状态进入工作台。进入工作台不自动开始接待。

| 定位器名 | 录制目标 |
|---|---|
| `new_message` | 带红点的完整客户行，不是单独红点或整个列表 |
| `current_user` | 当前会话的客户昵称，不能绑定某个固定人名 |
| `chat_window` | 当前聊天内容区域，不含输入框 |
| `reply_text` | 可输入并读回文字的输入框 |
| `button_send` | 当前会话的唯一发送按钮 |

完整说明见 [.locator/README.md](../.locator/README.md)。
三步未读验收比较的是未读会话行数：基线 → 原本已读买家发消息后增加 → 手动读完后回到基线。
不要求清空其他客户未读。

## 日常使用

保持匹配的聊天页可用；确认话术、账号和验收后，明确点击开始接待。
需要人工处理的客户会留下原因。结果未知时先检查实际页面，不直接恢复并重发。
“标记人工已处理”与“恢复后续接待”含义不同，均不会自动补发旧回复。

## 构建

```powershell
powershell -ExecutionPolicy Bypass -File .\build_windows.ps1
```

构建脚本创建独立环境、安装依赖、跑测试并使用 PyInstaller 打包；有 Inno Setup 时再生成安装器。
构建需要网络和足够磁盘空间。SDK、Qt 与其他依赖的再分发应遵循各自许可。
可选字体说明见 [assets/fonts/README.md](../assets/fonts/README.md)。
