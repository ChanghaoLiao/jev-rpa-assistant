# 故障排查

| 现象 | 应检查什么 | 下一步 |
|---|---|---|
| 五项都找不到定位器 | Store 所在用户目录、实际库名与 SDK 加载 | 使用程序打开的录制工程，保存后重新接入；不要复制他人的 Store |
| `new_message` Validate 失败 | 是否录了完整客户行、规则是否绑定昵称或序号 | 闲鱼＋Edge 回程序执行自动整理；不支持的平台需独立适配 |
| 未读数为零 | 当前列表是否有未读、是否已加载目标会话 | 保留等待，使用原本已读的测试买家验证变化 |
| 视觉返回不可读 | 实际上传范围、模型原始返回、角色方向 | 在识字历史查看证据，不能只放宽所有判断 |
| Jev 选择 HUMAN | 当前分类、话术适用／排除条件与原始问题 | 调整真实业务规则后再测，不靠提高审批绕过问题 |
| 画面或消息变化 | 客户、内容摘要、尺寸、滚动与截图前后状态 | 重新读取，不复用旧候选；查看对应审计步骤 |
| 输入框已有草稿 | 是否有人手动输入或上轮粘贴后停止 | 人工处理草稿，不允许自动覆盖 |
| 发送结果未知 | 点击意图、调用返回、网页消息序列与匹配原因 | 检查实际会话；不直接重发，确认后恢复后续接待 |
| 不能开始接待 | 当前平台的未读、视觉、话术和发送验收状态 | 查看按钮旁阻挡原因，完成实际缺失项 |
| 费用未知 | 模型用量是否返回、单价与计费口径是否匹配 | 核对供应商记录，不把未知写成零 |

反馈时说明版本、系统、入口、操作顺序、预期和实际结果。
仅提供脱敏文字证据，不上传真实聊天图片、Token、Cookie 或完整配置。
